# AGENTS.md

Personal homepage dashboard with two frontends:
- **Web**: Static HTML generated from YAML (no server, open `output/index.html` directly)
- **CLI TUI**: Go terminal UI (bubbletea/lipgloss), split across `cli/tui/{main,types,themes,utils}.go`

## Build

```bash
make build                     # Both web + CLI
make build-html                # Web only → output/index.html
make build-cmd                 # CLI only → output/tui
python3 web/build.py --example # Build example.html from services.example.yml
python3 web/build.py --open    # Build + open in browser
python3 web/build.py --no-health # Build without health check feature
```

Go binary built with `cd cli && go generate ./tui && go build -ldflags="-s -w" -o ../output/tui ./tui`.

## Validation

No automated tests. Verify manually:
- **Python**: `python3 -m py_compile web/build.py`
- **Go**: `cd cli && go generate ./tui && go build -ldflags="-s -w" -o ../output/tui ./tui`
- **HTML**: browser DevTools or W3C validator

## Critical gotchas

1. **Never edit `output/index.html`** — it's generated by `web/build.py`. Edit `web/src/template.html`, `style.css`, `script.js`, or `health.js` instead.
2. **`services.yml` is gitignored.** Only `services.example.yml` is tracked. CI builds and deploys the example.
3. **`cli/tui/services.yml` is a build artifact** — `//go:generate cp ../../services.yml services.yml` in `main.go` handles the copy. Gitignored, embedded via `//go:embed`.
4. **Emoji variation selectors break TUI alignment.** Always use `realStringWidth()` (strips VS16/VS15) instead of raw `ansi.StringWidth`. Strip variation selectors from emoji in `services.yml` too (e.g., 🛰 not 🛰️).
5. **Manual border drawing for detail/header boxes** — lipgloss `.Width()` has emoji width bugs. Borders are drawn with string concatenation, not lipgloss containers.
6. **Global `var p *tea.Program`** — only way to send bubbletea messages from goroutines (health checks). Acknowledged hack, don't refactor.
7. **Health checks use `fetch` with `mode: 'no-cors'`** — opaque responses count as "online", only network failures count as offline.

## YAML config

Groups and services defined in `services.yml`. See `services.example.yml` for the schema. Services with no valid groups get a synthetic `nogroup` category. An implicit `all` group is appended automatically.

## Conventions

- Vanilla HTML/CSS/JS (no frameworks), Go for TUI, Python only for build script
- localStorage keys use `homepage-` prefix
- Go: `lipgloss.DoubleBorder()` with theme-specific `t.Border` color for borders
- TUI files: `types.go` (structs), `themes.go` (colors/borders/applyTheme), `utils.go` (helpers/config/install), `main.go` (model + tea program)
- CSS: dark theme default (`#0a0a0b` bg, `#6366f1` accent), light via `.light` class on `:root`
- TUI settings persist to `~/.config/homepage/tui.json`
- CI: pushes to `main` rebuild `example.html` and deploy to GitHub Pages
